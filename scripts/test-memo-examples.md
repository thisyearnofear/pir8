# Legacy Zcash Memo Testing Examples

> **Status:** obsolete legacy reference.

PIR8 no longer uses a cross-chain Zcash memo bridge as its core privacy architecture. Current privacy-oriented gameplay is centered on Solana session-key delegation, with the important limitation that delegation and match state remain publicly inspectable on-chain.

The commands previously documented here referenced `test:memo` and `cli` package scripts that are not present in the current root `package.json`. Do not use this file as a setup or testing guide.

Current development commands are documented in [../docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md).
